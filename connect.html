Creator Studio

Connect AI

Build characters with your own ChatGPT. Make a personal key, add it to a Custom GPT, and your GPT can create characters and save the images it makes straight to Persona.

1. Your API key

A key lets an AI tool act for your account: create characters and add images, within your upload allowance. Treat it like a password. You can remove a key at any time.

2. Make your Custom GPT

About five minutes, once. Needs a ChatGPT plan that can create GPTs (Plus, Team or Enterprise).

  1. Open the GPT builder

    In ChatGPT, go to Explore GPTs → Create, then open the Configure tab. Or go straight to chatgpt.com/gpts/editor.

  2. Name and instructions

    Name it Persona Character Builder. Copy these instructions into the Instructions box:

    Loading…

    Under Capabilities, keep Image Generation switched on.

  3. Add the Persona action

    At the bottom, choose Create new action → Import from URL and paste:

  4. Add your key

    In the action, set Authentication → API Key → Auth type: Bearer, and paste the key from step 1.

  5. Try it

    Save the GPT (Only me is fine), then say "Make me a new character". When ChatGPT asks to talk to persona-ai-characters.vercel.app, choose Allow.

    New images arrive in your Studio hidden, so you always choose what goes live.

Other tools

The same key works anywhere that can call a web address: Zapier, Make, n8n, Shortcuts or your own code. Full reference: openapi.json.
